# ASCII HyperMaze

Топдаун-лабиринт в гиперболической геометрии с ASCII-рендером на Canvas.

## Описание

Игра представляет собой лабиринт, построенный на основе гиперболической тесселяции {7,3} (регулярные семиугольники). Пространство искривлено: короткие циклы, "невозможные" повороты, порталы.

## Ключевая механика

**"Игрок неподвижен, мир движется"** — каждый шаг игрока реализуется как изометрия, центрирующая игрока в (0,0). Камера всегда смотрит на центр диска Пуанкаре.

## Управление

- **WASD / Стрелки** — движение по геодезическим направлениям
- **Пробел** — рывок (локальная изометрия с большим шагом, кулдаун 5 сек)
- **E** — взаимодействие с порталом
- **ENTER** — начать игру / перезапустить после окончания

## Цель

Собрать 5 сигилов (✶) и дойти до выхода (E), избегая стражей (§) с гиперболической видимостью.

## Запуск

```bash
npm install
npm run dev
```

Игра откроется в браузере на `http://localhost:3000`.

## Структура проекта

```
src/
  main.ts              # Точка входа, игровой цикл
  core/
    hyper.ts          # Гиперболические изометрии (Möbius)
    tiling.ts         # Тесселяция {7,3}
    fov.ts            # Поле зрения в H²
    portals.ts        # Порталы и телепорты
    rng.ts            # Генератор случайных чисел
  game/
    world.ts          # Генерация уровня
    sim.ts            # Симуляция игры
    fsm.ts            # Конечный автомат состояний
  render/
    canvas_ascii.ts   # Canvas2D ASCII рендер
    hud.ts            # Интерфейс игры
```

## Технологии

- TypeScript
- Vite
- Canvas2D API
- Гиперболическая геометрия (модель Пуанкаре)

## Особенности

- Гиперболическая геометрия с изометриями Мёбиуса
- Тесселяция {7,3} для генерации лабиринта
- Порталы для телепортации
- Стражи с гиперболическим FOV
- ASCII-рендер вне терминала на Canvas
